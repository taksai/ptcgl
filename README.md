# PTCGL Log Analyzer

Pokémon TCG Live の英語対戦ログを貼り付けて、1手ずつ盤面を振り返るローカルUIです。
`kaggle_pokepoke_2/tools/visualizer/player.html` の盤面レイアウトを独立したアプリに流用しています。

## 起動

Node.js 20以上で、依存パッケージのインストールなしに動きます。

```sh
npm start
```

ブラウザで <http://127.0.0.1:8765> を開きます。停止はターミナルで Ctrl+C。
別のポートなら `PORT=8766 npm start`。`index.html` の直接ダブルクリックではなく、HTTPで開いてください。

1. 「ログを貼り付け」にPTCGLからコピーした1対戦分の英語ログを入力します。
2. 「ログを分析する」を押します。`.txt` / `.log` の読込にも対応しています。
3. 左の行動ログ、下部の再生ボタン・スライダー、右のターン集計から位置を選べます。
4. カードをクリックすると詳細、トラッシュを開くと記録されたカードを確認できます。

解析は日本語辞書・画像の通信を待たずに実行します。読み込み後は盤面へ移動し、入力に問題があるときはエラーの位置へ移動します。日本語辞書の取得が終わると表示を更新します。

「サンプルログ」でデモを試せます。手元に `examples/sample.txt` があればそれを優先し、なければ架空の `examples/demo.txt` を開きます。添付ログとその検証用ファイルはローカルにのみ保持し、Gitには含めません。
フォーカスが入力やボタンにないとき、← / →で前後、スペースで再生・停止します。

## 表示と分析

- バトル場・ベンチ・手札の既知カードと非公開枚数・サイド・スタジアム・トラッシュ
- 進化、付属エネルギーカード、累計ダメージの変化
- 行動ログの検索、ワザ・きぜつ・サイド取得・警告による絞り込み
- プレイヤー視点の切替、1手ずつの移動、自動再生、速度変更
- ワザダメージ、きぜつ、サイド取得、コイン、ターン別推移、カードの使用回数
- 原文の行番号と曖昧さ・未対応行の警告、解析JSONのダウンロード

同梱デモは実在のカード名を使った、UI動作確認用の架空の対戦です。カードルールの正しさを示すものではありません。

## カード名・参考券面の流用（任意）

```sh
python3 scripts/import-assets.py /path/to/kaggle_pokepoke_2
```

引数を省略すると `~/workspace/kaggle_pokepoke_2` を読み込みます。
既存の日本語辞書・カードデータ・券面を `assets/` に取り込みます。
素材なしでも日本語名とTCGdexの日本語参考券面を自動表示します。

- カードは**英語名**で照合します。PTCGLセットIDとの完全一致ではありません。
- 複数の同名カードが辞書にある場合、先頭の参考情報を表示します。券面の一致を保証しません。
- HP・ワザ・特性の説明は参考情報です。ゲームルールや能力による補正は計算しません。
- 画像は元プロジェクトのチーム内利用限定・再配布禁止の扱いを継承します。`assets/` はGitに含めません。
- 流用元は [PROVENANCE.md](PROVENANCE.md) を参照してください。

## 復元の限界

これはログから確認できる事実を振り返るツールです。勝率評価・最善手探索をするゲームエンジンではありません。

- 現在の対応形式は、`(sv6_130) Dragapult ex` のようなカードID付き英語ログです。日本語ログや別形式は未対応行として通知します。
- 同名・同IDのポケモンが複数いる場合、ログだけでは個体を特定できません。仮の対応に `?` を付けます。エネルギー・ダメージ・進化先は要確認です。
- 同名個体の仮置きときぜつ時の明示的な付属カード内訳が食い違う場合、トラッシュは原文の内訳を優先します。残る個体の付属カードは仮置きのままです。
- 原文のダメカン対象と実際の所有者が食い違う場合、勝手に所有者を書き換えず警告し、該当しうるカードのダメージを `数値 + ?` と表示します。
- ダメージは原文の数値を集計し、オーバーキルや軽減を再計算しません。ダメカンは自己ダメージや対象不明の行を含む別集計です。
- 初期状態が揃っている場合のみ、60枚デッキ・6枚サイドを前提に枚数を追跡します。途中からのログでは初期枚数を不明にします。
- 非公開カードは推測しません。未対応の効果、特殊状態、山札への特殊な移動などは原文・警告で確認してください。未対応行がある場合、それ以降の盤面や枚数は不完全な可能性があります。
- 「カード使用」は場に出す・進化・トレーナー使用を含むログ上の回数で、採用枚数ではありません。
- 読み込んだログはブラウザのメモリ内で処理します。リロードすると読み込んだ状態は消えます。対戦ログのアップロードはありません。日本語画像の自動取得では、カードID・画像URLだけをTCGdexへリクエストします。

## 開発

```sh
npm test
npm run check
```

- `src/parser.js`: テキスト解析、各行動時点の独立したスナップショット、集計
- `src/board.js` / `src/board.css`: 元UIから流用した盤面と参考カード表示
- `src/app.js` / `src/app.css`: ログ読込、再生操作、分析画面
- `scripts/server.mjs`: localhost限定の静的サーバー（ソース・素材・サンプルだけを配信）
- `tests/parser.test.js`: 架空のデモと主要な盤面遷移の回帰テスト

## 公開サイト

https://taksai.github.io/ptcgl/

GitHub Pagesで公開しています。ログの貼り付け・解析はブラウザ内で完結し、入力内容は送信しません。
スマホでも日本語のカード名・行動要約・画像を自動表示します。端末に画像を用意する必要はありません。盤面は画面幅に収まり、カードをタップして拡大できます。
「手元の画像（任意）」で `assets` フォルダを選ぶとローカルの日本語参考券面を優先します。
選択したファイルはそのページのメモリ内だけで使い、画像や辞書をアップロードしません。再読み込み後は再選択してください。

`master` へのpush時に `.github/workflows/pages.yml` がテストと `npm run build` を実行し、`dist/` を公開します。
公開ビルドはファイルを明示してコピーし、添付ログ・ローカルの効果辞書・画像を除外します。日本語名と公開カードIDの索引だけを含めます。汎用の架空デモのみ同梱しています。

## 日本語画像の自動取得

- `data/japanese-index.json` はカード名・ワザ名の対訳と、TCGdexの公開日本語カードIDの索引です。画像やカード効果本文、私的ログは含みません。
- 英語のPTCGL IDを公開APIに照会して英語名を確認し、日本語の同名カードを照合します。ポケモンはHP・進化段階・にげる・ワザのエネルギー構成とダメージも比較します。
- 日本と英語圏では収録番号が違うため、表示は「日本語参考券面」です。効果テキストの完全一致やホイルの一致を保証しません。
- 日本語画像が未収録、照合不一致、通信エラーの場合は「日本語画像なし」と日本語名を表示します。勝手に英語画像には切り替えません。
- APIは同時6件まで、同じカードへのリクエストはページ内で共有します。1カードあたり最大18候補までを確認します。
- TCGdexに送るのはカードIDと画像URLです。ログ本文・プレイヤー名・ファイルは送信しません。元プロジェクトの制限付き画像は公開していません。
- 行動要約は日本語で表示し、選択した行の英語原文も併記します。日本語カード名でも検索できます。

画像提供元・仕様: https://tcgdex.dev/assets

索引更新: `python3 scripts/build-japanese-index.py /path/to/kaggle_pokepoke_2`。元データ全体から名称対訳だけを取り、TCGdexの公開日本語カード一覧を取得します。
